Crie um aplicativo web completo (frontend + backend + banco de dados) para controle de dieta, calorias e consumo de água.

STACK:
- Frontend: React + TailwindCSS + Framer Motion (animações)
- Backend: Node.js com Express
- Banco de dados: SQLite (simples e leve)
- Estrutura organizada em pastas (client/server)
- Código limpo e comentado

OBJETIVO DO APP:
Um app simples, bonito e moderno para controle diário de calorias, alimentos consumidos, ingestão de água e perfil do usuário, com linguagem totalmente informal e motivacional.

---------------------------------------

FUNCIONALIDADES PRINCIPAIS:

1) DASHBOARD (TELA PRINCIPAL)
- Mostrar:
  - Total de calorias consumidas no dia
  - Meta de calorias (definida pelo usuário)
  - Barra de progresso animada
  - Consumo de água com barra animada
- Mensagens motivacionais INFORMAL, tipo:
  - "Tá mandando bem, meu patrão!"
  - "Segue firme, monstro!"
  - "Vai perdendo medida aí, gigante!"
  - "Hoje tá voando!"
- As mensagens devem mudar dinamicamente com base no progresso

---------------------------------------

2) CONTROLE DE ALIMENTOS

- Campo de busca com base de dados de alimentos
- Cada alimento deve conter:
  - nome
  - calorias por 100g
  - categoria

- Permitir adicionar alimentos consumidos com diferentes medidas:
  - gramas
  - colher (sopa/chá)
  - concha
  - xícara
  - unidade

- Converter automaticamente para calorias com base na medida
- Permitir:
  - adicionar refeição
  - remover refeição
  - editar refeição

---------------------------------------

3) CONTROLE DE ÁGUA 💧

- Definir meta diária de água (em litros)
- Botões rápidos:
  - +200ml
  - +300ml
  - +500ml
- Barra de progresso animada

- Feedback dinâmico:
  - "Bora beber água, campeão!"
  - "Hidratação tá em dia!"
  - "Quase lá, não vacila!"

- SISTEMA AVANÇADO:
  - Histórico diário de consumo
  - Gráfico dos últimos 7 dias
  - Sistema de horários:
    - manhã / tarde / noite com mensagens
  - Barra muda de cor:
    - vermelho (baixo)
    - amarelo (médio)
    - verde (meta atingida)
  - Animação de água subindo
  - Efeito splash ao adicionar água
  - Sistema de streak:
    - mostrar dias consecutivos batendo meta
  - Permitir editar/remover registros
